# Protected ABI surface — Tesserafin server assemblies whose PUBLIC API is
# compared between a pull request's merge base and its head by
# ci/abi-compat.sh (workflow: .github/workflows/ci-compat.yml).
#
# THIS FILE IS CONTRACT DATA, NOT A CONVENIENCE LIST.
# Removing an entry does not silently shrink the checked surface: the script
# asserts the entry count against ABI_EXPECTED_ASSEMBLY_COUNT_DEFAULT, which
# lives in ci/abi-compat.sh. Any change here must be made in both places and
# is therefore visible in review.
#
# Selection policy — an assembly belongs here when it is (a) first-party,
# (b) produced by a clean `dotnet build Tesserafin.Server -c Release`, and
# (c) a shared or plugin-facing contract: something a plugin or another
# assembly compiles against rather than an internal implementation detail or
# a host executable. Third-party dependencies, test assemblies, analyzer
# assemblies and the host executable are deliberately excluded.
#
